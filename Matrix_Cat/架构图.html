Matrix_Cat / 项目结构

Python 框架。协议直连（curl_cffi + 自算签名），登录用 CloakBrowser 指纹浏览器。四层清晰:前端 / 后端 / 采集 / 存储,加两个横切层,最外层一个运行程序。

协议优先 自算签名 + curl 直连,非 RPA CloakBrowser 一号一 profile 已落地 小红书 拉平 全在项目根,无 crawler_spider 层
$ python run.py → 网页总控台 http://127.0.0.1:8799

各层详解

文件 : 干什么

前端 frontend/

网页总控台的界面。纯前端,不含逻辑。

  • index.html选号 / 填标题正文图 / 发布;inline JS,只 fetch /api/*

后端 backend/

aiohttp 服务,把各平台统一成一套网页接口。

  • server.py适配器注册表 _ADAPTERS + /api/login·publish·accounts;serve 前端

采集 collectors/

每平台一个自包含文件夹,登录 + 发布。

  • xhs_publisher/小红书:run.py(CLI)+ xhs/(下方)+ tests + data/
  • xhs/browser·loginCloakBrowser 扫码登录 + 页内 _webmsxyw 签名机
  • xhs/cos·note·publishCOS 直传素材 · 拼笔记体 · 发布编排
  • xhs/signer·accountsx-s 签名 · AccountStore + a1/b1 指纹契约
  • _template/新平台起手模板(复制改名即用)

存储 storage/

账号会话的持久化层。

  • session_store.py通用 AccountStore:json 落盘 + 按 user_id 去重 + 风控冷却
  • data/uploads/网页上传的临时素材(不进 git)

shared 公共 · 跨层复用

各层共用的工具,别重复造。

  • http.pycurl_cffi 会话工厂 + 代理路由(境内直连 / 海外走 VPN)
  • signing.pysha256 / hmac / hkdf / ecdh-p256 / aws4 / base64(对过标准向量)
  • io_utf8 · pathsutf-8 控制台引导 + logging · data 目录约定

config 全局配置

可调项集中一处,别处只 import。

  • settings.pyUA · CloakBrowser 参数 · curl 指纹 · 代理(KDL 北京出口)· 超时
04

加一个新平台

三步接进网页总控台 
:: 复制模板,改包名
xcopy /E /I collectors\_template collectors\douyin_publisher
cd collectors\douyin_publisher & ren pkg douyin
  1. 填 douyin/config.py:PLATFORM · COOKIE_DOMAIN · 域名接口路径。
  2. 补 login / signer / uploader / content / publish 里的 TODO(config、accounts 已接好 shared + storage)。
  3. 在 backend/server.py 的 _ADAPTERS 加一条适配器 → 自动接进网页总控台。

数据落盘两处: 每个平台的 accounts.json + CloakBrowser profiles 在 collectors/<平台>_publisher/data/;网页上传素材在 storage/data/uploads/。两处都在 .gitignore,登录态 = 账号凭证,绝不进 git。
